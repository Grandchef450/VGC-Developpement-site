FAQ

Ce qu'on nous demande le plus.

« Debadger », ça veut dire quoi ?

Ce sont des véhicules inspirés de vraies marques dont les logos et badges ont été retirés (« debadged »). On garde la silhouette et le niveau de détail, sans le nom de la marque sur la carrosserie — le format habituel pour les serveurs RP.

Comment obtenir un véhicule du catalogue sur mon serveur ?

Rejoins le Discord, ouvre un ticket avec le nom du véhicule (ou de la galerie de marque) et ton framework. On te répond avec les conditions et, si besoin, une session sur le serveur showcase pour le tester avant.

Le serveur showcase est-il accessible à tout le monde ?

Il est ouvert à la demande, aux membres du Discord. La commande de connexion est partagée dans un salon réservé une fois le serveur démarré. Pas d'IP publique, pas de file d'attente : une session, un créneau.

Vous faites des scripts pour quel framework ?

ESX, QBCore, Qbox et standalone. Précise ton framework, ton inventaire (ox_inventory, qb-inventory…) et ton système de target dans le ticket : c'est ce qui détermine le temps d'intégration.

Combien ça coûte ?

Chaque demande est chiffrée dans son ticket, selon le véhicule, le script ou le MLO concerné. Aucun paiement hors Discord : si quelqu'un te contacte ailleurs au nom de VGC, ce n'est pas nous.
